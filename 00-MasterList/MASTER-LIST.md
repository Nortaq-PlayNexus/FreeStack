## THE 20-MINUTE STARTER STACK (do this first)
1. Cloudflare account (free) - Pages, Workers, R2, DNS, email routing in one place.
2. GitHub account - repos + Actions (cron/CI).
3. Neon (free Postgres) OR Supabase - your database.
4. OpenRouter (free) - your AI brain.
5. Resend (free) - your email.
6. is-a.dev PR - your free domain.
Then deploy a Cloudflare Pages site + a Worker API + connect everything. Framework for each: see folders 01-15.

## THE "FULL POWER FOREVER" STACK (when free tiers aren't enough)
1. Oracle Cloud Always Free VM (2 Arm / 12GB / 200GB) = your 24/7 everything server.
2. Everything self-hosted there (Docker): Postgres, Meilisearch, Ollama, Uptime Kuma, n8n, PocketBase, sish tunnel, MCP servers.
3. Cloudflare in front for SSL/CDN/DDoS + free domain from is-a.dev.
4. GitHub Actions as free cron + auto-deploy + backup.
Details: 15-Meta-Framework.
